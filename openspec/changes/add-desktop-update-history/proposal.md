# 提案：Desktop 更新发现与版本历史

## Why

私有更新检测已为后台提供客户端当前版本和更新选择，但 Desktop 缺少统一的版本发现界面。“关于”当前只显示安装版本，用户需要明确知道新版本可用，并查看适用于当前系统平台的发布说明与历史记录。

## What Changes

- 在“关于”区域显示当前 Desktop 版本、可用更新入口和当前系统平台适用的历史版本记录。
- 沿用私有更新检查，在启动时和用户手动检查时报告当前版本及可选 `userId`；启动检查失败静默处理，不影响应用启动。
- 有新版本时提示“有新版本可安装”；用户主动打开后查看该版本说明并继续现有更新确认流程。
- 扩展私有更新检查响应，返回当前平台可用的发布历史及其版本和更新说明；不增加独立历史查询接口。
- 不增加常驻系统状态栏图标或入口。

## Capabilities

### New Capabilities

- `desktop-update-discovery`: 在 Desktop“关于”区域呈现当前版本、可用更新和当前平台发布历史。

### Modified Capabilities

无。该提案新增版本发现界面能力，并依赖 `add-private-desktop-updates` 提供的检查接口。

## Impact

- Electron Desktop 主进程的“关于”界面、更新检查提示与本地化文案。
- 私有更新检查响应协议和后续管理后台需维护的发布说明数据。
- 本提案依赖 `add-private-desktop-updates` 定义的私有更新接口与客户端检查行为；不修改现有打包、差分下载或签名校验机制。
