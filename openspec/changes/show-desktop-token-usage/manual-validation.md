# 手工联调

先部署包含本人状态和用量接口的 `aicode-app-dsh`，再发布并让 Desktop 使用包含本变更的 `dsh-pro-auth`。所选环境须启用 Aicode 登录并配置 API origin；避免在终端、日志或截图中记录登录令牌和完整 Key。

1. 使用没有管理页面 Key 查询权限的账号登录 Desktop，在左下角账户菜单打开“用量统计”。确认弹窗显示本人用户名、Key 掩码和状态，并将掩码与 TokenHub 中的当前 Key 对照。
2. 确认今日、本周、本月总 token 与 TokenHub 在对应自然周期内的当前 Key 数据一致；日期和时间表示最近一次整体刷新的发起时间，不显示时区字样。
3. 点击刷新，确认整体时间更新。模拟一个周期查询失败，确认其他结果保留，失败行可单独重试且不改变整体刷新时间。
4. 在允许的测试环境中轮换 Key 或使用受控接口响应模拟版本变化；确认不同版本的掩码和用量不会组合展示，并可整体刷新恢复。
5. 在查询期间关闭弹窗、登出或切换账号，再打开弹窗，确认旧用户的结果不出现。检查失效登录和不可查询 Key 显示错误或不可用状态，不显示为零。
6. 检查中英文、深浅主题、窄窗口、键盘操作和弹窗关闭；检查未启用 Aicode 的 profile 沿用原有行为。
